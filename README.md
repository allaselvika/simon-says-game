🎮 Simon Says Game
https://allaselvika.github.io/simon-says-game/

A fun and interactive Simon Says memory game built using HTML, CSS, and JavaScript.
The game challenges players to remember and repeat an increasingly long sequence of colors.
Each round adds a new color, testing memory and focus.



🚀 Features

✔️ Simple and responsive UI

✔️ Random color sequence generation

✔️ Level-based difficulty

✔️ Sound & visual feedback

✔️ Fully built using HTML, CSS, and JavaScript (no frameworks)



🧠 How the Game Works

The game flashes a random color.

The player must click the colors in the exact same order.

Each correct attempt increases the level.

If the player clicks the wrong color → Game Over, and the level resets.



📂 Technologies Used

HTML – structure

CSS – styling

JavaScript (app.js) – game logic, events, animations



📁 Project Structure
├── index.html
├── style.css
└── app.js



▶️ How to Play

Open index.html in your browser.

Click a key or button to start the game.

Watch the sequence and repeat it correctly.

Try to reach the highest level!
